# Project Overview

## Context

2026년 9월부터 이택규·주수빈이 학교 CMP 프로그램과 공학및 지식실무 교과목에서 함께 진행하는 연구입니다. MicroLED의 측벽 결함이 캐리어 재결합에 미치는 영향을 Sentaurus TCAD로 해석하고, 공통 기준 모델에서 두 캐리어 구속 구조를 비교합니다.

## Research Question

동일한 epitaxy, mesa 크기, 측벽 손상 및 전류 밀도 조건에서 Carbon 고저항 edge(A)와 국부 AlGaN 측면 장벽(B)이 측벽으로의 캐리어 이동과 SRH 재결합을 어떻게 바꾸는가?

## Responsibilities

- **주수빈:** common baseline 코드·실행 조건 검토, 계산 시간 및 NtSide split-run 상태 확인, Project B 설계, 발표용 문헌 근거·비교 방법 정리.
- **이택규:** common baseline 구축·검증, Project A 설계, 공동 연구 기록 관리.
- **공동:** baseline 동결, 동일 전류 밀도 기준 A/B 비교, 결과 검증과 보고.

담당 범위와 완료 여부는 구분합니다. B의 완성된 성능 결과가 공개 기록에 존재하는 것으로 해석하지 않습니다.
