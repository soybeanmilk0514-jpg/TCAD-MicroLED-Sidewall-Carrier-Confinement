## 기존 calibration checkpoint

[원본 P2 CSV](../CMP/tcad/P2_MG_CALIBRATION/CALIBRATION_RESULTS.csv) 및 [설명](../CMP/tcad/P2_MG_CALIBRATION/README.md)에는 300 K에서 Mg=9.59e18 cm⁻³ 설정에 대해 p=3.00033017418e17 cm⁻³가 기록되어 있습니다. 이는 p-GaN incomplete-ionization calibration 기록이며 MicroLED 측벽 장벽의 성능 결과가 아닙니다.

[원본 P3 기록](../CMP/tcad/P3_BASELINE_MICROLED/README.md)은 GaN PiN baseline 재현 checkpoint입니다. 원본 기록 날짜와 조건을 유지하며 현재 MQW MicroLED의 검증 완료를 뜻하지 않습니다.

이번 정리에서는 새로운 시뮬레이션·측정·수치 보간을 수행하지 않았습니다.
